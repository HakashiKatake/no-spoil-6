Get the extension.

Download the ZIP for your browser and follow the manual installation steps.

Chrome

Also for Edge, Brave, Opera, and Vivaldi.

Download ZIP ↓
Installation steps
  1. Extract the downloaded ZIP.
  2. In Chrome, open chrome://extensions. In other browsers, open the extensions manager.
  3. Turn on Developer mode, select Load unpacked, and choose the extracted folder.

Firefox

For Firefox Desktop 140 or later.

Download ZIP ↓
Installation steps
  1. Extract the downloaded ZIP.
  2. Open about:debugging and select This Firefox.
  3. Choose Load Temporary Add-on and select manifest.json. Firefox removes temporary add-ons when it restarts.

Safari

Extension bundle for Safari on Mac.

Download ZIP ↓
Installation steps
  1. Extract the ZIP. In Safari → Settings → Advanced, enable Show features for web developers.
  2. If the Developer tab offers Add Temporary Extension, select the extracted folder and grant website access.
  3. On earlier versions of Safari, use Apple’s Safari Web Extension Packager.

Questions?

What does the shield look for?

It looks for GTA 6 references in post text, titles, image descriptions, and links. That includes news and trailers. Spoilers in images, video, or audio can slip through when there’s no matching text or metadata.

Can I leave it on all the time?

Yes. Always on is the default. Choose Schedule in the toolbar popup to use a start date, daily browsing hours, or both. Times follow your device’s local clock.

Does it work in social media apps?

The shield works on websites you open in a supported browser. It can cover posts on instagram.com, for example, while the Instagram app is outside its reach.

What happens to the pages I browse?

Page content and activity counts stay on your device. Settings can move to another browser in a file or through optional browser sync. Read the privacy policy for details.
